# Supply-Chain-Performance-Dashboard
Interactive Power BI dashboard analyzing supply chain costs, inventory, transportation, product quality, defect rates, and inspection outcomes.

## Project Overview

This project brings key supply chain indicators into a single reporting experience. The dashboard supports analysis of costs, quantity sold, SKU coverage, defect rates, inspection results, and location-level performance, with interactive filters for exploring different operational segments.

## Dashboard Highlights

### Main Dashboard

**KPI cards**
- **Total SKUs** — overall SKU count.
- **Total Cost** — aggregated supply chain cost.
- **Average Defect Rate** — average recorded defect rate.
- **Total Quantity Sold** — total quantity sold.

**Visual analysis**
- **Average Defect Rate by Product Type:** compares quality outcomes across product categories.
- **Quantity Sold by Transportation Mode:** compares quantity moved across transportation modes.
- **Cost by Location:** geographic view of location-level cost.
- **Quantity Sold vs. Total Cost:** scatter chart for comparing volume and cost across locations.
- **Inspection Results:** funnel-style view of SKU counts by inspection result.
- **Supply Chain Summary:** matrix-style breakdown by route, location, product type, and total cost.

**Interactive filters**
- Route
- Location
- Supplier Name
- Product Type
- Customer Demographics

### Details Page

A detailed table provides a closer view of:
- Location
- Product Type
- Total Cost
- Total Shipping Cost
- Total Quantity Sold

## Tools & Technologies

- **Microsoft Power BI Desktop** — dashboard design, data modelling, interactive visuals, and report layout.
- **Power BI visualisations** — KPI cards, column chart, bar chart, map, scatter chart, funnel, matrix, and detail table.
